# blablatest

blablatest

**Play: https://jumphp.net/blablatest**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): games and applications in PHP, on the desktop and in the browser.
The game is in `games/blablatest/`.

```bash
bin/jumphp install blablatest    # dependencies (everything runs in Docker)
bin/jumphp run blablatest        # run it on the desktop
bin/jumphp test blablatest       # checks + a headless demo
```
