# blablatest

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install blablatest   # dépendances
bin/jumphp run blablatest       # jouer sur le bureau
bin/jumphp test blablatest      # vérifications + test automatique sans écran
bin/jumphp build blablatest     # version navigateur -> dist/web
bin/jumphp serve blablatest     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
